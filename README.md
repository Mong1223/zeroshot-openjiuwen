# ZeroShot — openJiuwen Challenge 2026

Агентная обвязка (harness) на **openJiuwen** для решения пакета задач (`math`, `data_analysis`, `search`, `coding`
и незнакомых типов) при ограниченном бюджете токенов.

## Запуск

```bash
docker build -t zeroshot .
docker run --rm --read-only --tmpfs /tmp -e HOME=/tmp \
  -e LLM_BASE_URL=... -e LLM_API_KEY=... -e BUDGET=100000 \
  -v /path/to/tasks:/data/tasks \
  zeroshot python /app/run_agent.py --tasks-dir /data/tasks
```

- Ответ каждой решённой задачи — `answer.txt` рядом с её `task.json`. Для `coding` исправляется код в `workspace/`,
  в `answer.txt` пишется `DONE`.
- Для задач, признанных нерешаемыми, `answer.txt` **не создаётся**.
- Журнал работы — в stderr; итог и вызовы модели — в `/tmp/zeroshot/` (`summary.json`, `llm_calls.jsonl`).
- Программа всегда завершается с кодом 0: сбой одной задачи не мешает остальным, ответы пишутся сразу.

## Как устроено

Каждая задача поднимается по «лестнице», от бесплатного к дорогому; следующая ступень — только если предыдущая
не справилась:

| Ступень | Что делает | Стоимость |
|---|---|---|
| 0. Правила | разбор текста и вычисление кодом: пошаговая арифметика, запросы к таблице, проход по базе знаний, перебор мелких правок кода по тестам | 0 токенов |
| 1. Короткий ответ модели | модель описывает решение (выражение, JSON-запрос, цепочку полей, исправленный файл), а **считает наш код**; при неудаче — модель пишет короткую программу | ~30–200 |
| 2. Агент openJiuwen | `ReActAgent` с инструментами (файлы, поиск, Python, запись кода, тесты) внутри папки задачи | ~500–1500 |

- Порядок задач: сначала бесплатный проход по всем, затем платный — по убыванию «баллы / ожидаемая цена»
  (оценщик цены — `harness/estimator.py`, по замерам и размеру файлов задачи).
- Учёт бюджета по правилу жюри (`выход + вход / 10`, включая упавшие запросы): худший случай бронируется до
  вызова, поэтому даже параллельные запросы не выходят за бюджет; резерв, контроль времени, повтор при 429.
- Любой правдоподобный ответ записывается сразу (неверный ответ не штрафуется); более поздний уровень
  перезаписывает его, если находит лучше.
- «Нерешаемо» объявляется только при надёжных признаках (нет сущности, поля, столбца, значения в данных);
  сомнительное отдаётся следующей ступени.

openJiuwen используется для всех обращений к модели (`openjiuwen.core.foundation.llm`) и как агент уровня 2
(`openjiuwen.core.single_agent.ReActAgent`, инструменты через `ToolCard` / `Runner.resource_mgr`).

## Структура

```
run_agent.py            точка входа
harness/
  config.py budget.py   настройки из окружения, счётчик бюджета (с бронированием) и времени
  estimator.py          оценка цены задачи для порядка платного прохода
  tasks.py              чтение задач, нормализация и запись ответа
  planner.py            порядок решения, параллельность, ступени
  llm.py                вызов модели через openJiuwen с учётом токенов
  agent.py              агент openJiuwen (уровень 2) и его инструменты
  jiuwen_setup.py       тихая настройка openJiuwen (без файлов журналов в read-only контейнере)
  normalize.py          нормализация текста (числа словами, синонимы, дроби)
  solvers/              решатели ступеней 0 и 1
tests/                  автотесты (pytest)
scripts/                локальные репетиции, генераторы проверочных задач
```

Зависимости: `requirements.txt` (openjiuwen) и `constraints.txt` (точные версии всех пакетов).
